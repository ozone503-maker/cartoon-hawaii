# Waterfall visual research notes

This branch treats the mapped Hawaiʻi Island falls as separate visual identities rather than one reusable waterfall prefab.

Reference targets used for the visual profiles:

- **Waiānuenue / Rainbow Falls** — broad ~80 ft drop, heavy mist and rainbow behavior, dark cave/pool character at the base.
- **Peʻepeʻe Falls / Boiling Pots** — successive large pools connected by cascades; exposed hexagonal basalt columns are a defining feature.
- **ʻAkaka Falls** — very tall, narrow free fall into a stream-eroded gorge; should read as a single elegant plunge rather than a stepped cascade.
- **Umauma Falls** — three visually distinct tiers with plunge pools between them.
- **Waipiʻo valley waterfall profile** — very tall, thin horsetail-style water against a massive valley wall; intentionally not rendered like ʻAkaka.
- **Upper Wailuku / sacred-stream thread falls** — narrow young-basalt incision, abrupt drops, bright water against dark rock, with each mapped thread given a different strand/stage pattern so the sequence does not look cloned.

Primary public references consulted: Hawaiʻi DLNR State Parks pages for Wailuku River State Park and ʻAkaka Falls State Park, GoHawaii waterfall material, and current descriptive references for Umauma and Waipiʻo valley falls.

The visual renderer remains deliberately stylized and phone-safe. It does not attempt fluid simulation or photogrammetric terrain reconstruction.
